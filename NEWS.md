# dqcheckrGUI 0.1.0

* Initial release.
* Point-and-click Shiny front-end for `dqcheckr`:
  - Configuration wizard for setting up quality checks on a new dataset
    (identity, files, structure, columns, rules, overrides, custom checks,
    review/save)
  - Run panel for launching checks against incoming file deliveries and
    viewing the generated HTML report
  - History browser for reviewing past check results and historical drift
    comparisons between snapshots
